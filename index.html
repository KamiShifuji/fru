So wird gerechnet

Datenbasis sind die hochgeladenen FFLogs-Reports, die auch auf Tomestone liegen. Es zählen nur Abende, die an einem Dienstag, Donnerstag oder Sonntag begonnen haben. Der 31.10. (Samstag, inkl. der Nacht auf den 01.11.) ist deshalb Party Finder und fehlt hier. Der 01.11. abends war zwar ein Sonntag, aber ein PF-Abend mit Randoms (nur 3–4 Stammspieler) und zählt deshalb ebenfalls nicht. Der 25.10. besteht aus zwei Blöcken und ist ein Abend.

Seit dem 20.11.2026 gleicht die Seite die Daten mit der FFLogs-API ab: volle Report-Links, Boss-HP mit Nachkommastelle, Spielerliste pro Pull und Positionsdaten für die Fehler-Analyse. Neue Reports kommen automatisch über die API dazu. 3 Pulls hatten in den ausgelesenen Daten keine Todesliste (03.11 Pull 13, 05.11 Pull 1, 05.11 Pull 12). Die API bestätigt: dort ist niemand gestorben, die Pulls endeten in der Zwischenphase ohne Massentod. Boss-HP korrigiert bzw. ergänzt: 15.11 Pull 3: 22 → 21.02 %, 19.11 Pull 2: ? → 100 %. Für 05.11 verlinkt die Seite das Log eines anderen Mitglieds derselben Session (gleiche Pulls und Dauern).

Boss-HP kommt aus FFLogs und ist der verbleibende Anteil in der erreichten Phase, seit dem API-Abgleich mit Nachkommastelle. Es wird nichts ergänzt oder geschätzt.

Der Balken „Weg bis zum Clear“ ist ein vereinfachtes Modell, keine echte Zeitmessung: Jede der fünf Phasen zählt gleich 20 %. Formel: Rest = 100 − [(Phase − 1) × 20 % + (100 − Boss-HP) / 100 × 20 %]. 100 % ist der Start von FRU, 0 % wäre ein Clear. Beispiel bester Pull: P3 bei 41,6 % Boss-HP = 100 − (40 + 11,7) = 48,3 % Rest.
